# Lotus Visual

Lotus Visual is a visual dashboard editing suite for Home Assistant.

## Installation with HACS

1. Open HACS in Home Assistant.
2. Add this repository as a custom repository of type **Integration**.
3. Install **Lotus Visual**.
4. Restart Home Assistant.
5. Add the **Lotus Visual** integration from **Settings > Devices & services**.

## Manual installation

Copy the `custom_components/lotus_visual` directory into the `custom_components` directory of your Home Assistant configuration, then restart Home Assistant.

## Repository structure

The Home Assistant integration is located in:

`custom_components/lotus_visual`
